# Q&A

**CrashLoopBackOff?** Read previous logs, probe, missing config, OOM, command error.

**Service has no endpoints?** Selector labels mismatch; pods not Ready.

**Why not Pod as the unit of CD?** Use Deployment/DaemonSet/StatefulSet.

**latest image?** Same Docker lesson; also imagePullPolicy.

**RBAC `*`?** Never for apps. Least privilege ServiceAccount.
