# Enterprise DevOps mastery path

Follow the numbered modules in order. Each module explains the tool, provides safe labs, shows enterprise integration, covers failures, and ends with practical questions and a capstone.

1. **AWS Cloud** — accounts, IAM, networking, compute, storage, databases, observability, security, cost control
2. **Linux and Bash** — administration, processes, filesystems, networking, systemd, troubleshooting, shell automation
3. **Git and GitHub/GitLab** — branching, merge requests, protection, releases, enterprise workflows
4. **Python for DevOps** — APIs, automation, testing, packaging, SDKs, safe operational tooling
5. **YAML, JSON, and templating** — schemas, anchors, validation, Jinja, configuration hygiene
6. **Networking, DNS, TLS, and load balancing**
7. **Docker and container fundamentals**
8. **Kubernetes fundamentals**
9. **Helm and Kustomize**
10. **OpenShift (OCP/ROSA)** — operators, routes, SCC, projects, cluster operations
11. **Databases for DevOps** — PostgreSQL, backups, HA, migrations, connection pooling
12. **Terraform** — modules, state, locking, environments, testing, policy
13. **Ansible** — inventories, roles, idempotency, secrets, AWX
14. **Jenkins and Groovy**
15. **GitLab CI/CD**
16. **Argo CD and GitOps**
17. **Artifact registries** — ECR, Harbor, Nexus, Artifactory
18. **ELK/OpenSearch logging**
19. **Prometheus, Alertmanager, and Grafana**
20. **Secrets and identity** — Vault, cloud KMS, OIDC, workload identity
21. **DevSecOps** — SAST, SCA, image/IaC scanning, SBOM, signing, policy as code
22. **SRE and production operations** — SLI/SLO, incidents, capacity, resilience, DR
23. **Platform engineering** — golden paths, internal developer platforms, Backstage
24. **Enterprise capstone** — secure multi-environment delivery platform

Current module: [01 — AWS Cloud](01-aws-cloud/) (foundations through capstone, labs, CLI cookbook, and interview Q&A).
