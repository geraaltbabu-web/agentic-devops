# Agentic DevOps demos

Two isolated, generic reference projects live in this repository:

- [`health-clinic-agent/`](health-clinic-agent/) — synthetic clinic API and safe deployment simulator.
- [`banking-platform/`](banking-platform/) — banking microservices, AI deployment controller, AWS Terraform, OpenShift/Kubernetes GitOps, and ELK observability.

No customer, employer, production, or real personal data is included.

Start with each project's own README. The banking project is the complete end-to-end example.
